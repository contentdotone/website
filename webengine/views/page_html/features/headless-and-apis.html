Render the way your teams build

WebEngine supports three output modes so developers, marketers, and integrators can work in the style that fits their implementation target. Switch instantly—no content migrations required.

Traditional

Serve fully rendered HTML with Parsley templates while keeping APIs opt-in. CORS denies external requests until configured.

Headless

Every route returns hydrated JSON for frameworks like Next.js or Nuxt. Instant and GraphQL APIs on with open CORS.

Hybrid

Render HTML by default while exposing JSON with ?toJSON. Best of both for omnichannel delivery.

No migrations

Switch modes per environment. Content models stay identical across Traditional, Headless, and Hybrid.
