Frequently asked questions

Common questions about the free tools.

Are these tools really free?

Yes. No sign-up, no credit card, no email gate. Enter a URL, get output. We may ask you for an email if you want a copy of a longer report, but it's never required to use the tools.

Do you store the data you pull from my site?

We retain the URLs you submit and the reports we generate so we can improve the tools. We don't sell that data, we don't use it to train third-party models, and you can request deletion at any time at privacy@content.one.

What AI models power the tools?

Mostly Anthropic's Claude family, with model selection per task. Instance Launcher uses Claude Opus for the deep analysis pass; the lighter audits use Claude Haiku to keep response time under a minute.

Do I need to be a Content.One customer to use them?

No. They're useful even if you stay on your current CMS. If the report or the audit turns up something you'd rather have help solving, then we'd be glad to talk.

Are more tools coming?

Yes. The grid is built to extend. If there's an audit or analyzer you'd find useful, tell us — most of these tools started as a request.

Want a tool we haven't built yet?

Most of the tools on this page started as a request from a marketing or content team. Tell us what'd be useful.
